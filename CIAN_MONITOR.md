# Монитор объявлений Циан

Отдельный раздел сайта: `https://kladovaya-altaya.github.io/cian-monitor/`.
Источник — список квартир агента: `https://www.cian.ru/cat.php?deal_type=sale&engine_version=2&id_user=118101459&offer_type=flat`. Монитор сверяет количество найденных ссылок с числом результатов поиска и не меняет статусы при неполной загрузке.
На главной странице «Кладовой Алтая» ссылки на него нет. В HTML раздела указан `noindex`, но это **не защита доступа**: репозиторий и GitHub Pages публичны, поэтому любой обладатель прямой ссылки сможет открыть страницу и данные.

GitHub Actions запускает `.github/workflows/monitor.yml` ежедневно в 18:00 по Москве (15:00 UTC). Для ручного запуска: **Actions → Monitor Cian → Run workflow**. Новые объявления появляются на странице после ближайшей успешной проверки, а не сразу после размещения на Циан. Workflow должен иметь право `contents: write`, чтобы сохранять `data/state.json`, таблицу, статус и Excel-файл в ветку `main`. GitHub Pages продолжает публиковаться из `main / (root)`; переключать его на публикацию через Actions не нужно.

До первого успешного запуска таблица пуста. Циан может показывать капчу или менять разметку; программа не обходит защиту. При ошибке проверки прежние данные сохраняются. «Нет в профиле» означает отсутствие объявления в последнем успешно прочитанном списке агента, а не подтверждение продажи. Срок считается с момента первого обнаружения монитором, а не с первоначальной даты публикации. «Первая цена» — первая цена, которую удалось записать монитором; это не обязательно первоначальная цена объявления на площадке.
