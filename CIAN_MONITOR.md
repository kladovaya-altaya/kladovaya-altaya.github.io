# Монитор объявлений Циан

Отдельный раздел сайта: `https://kladovaya-altaya.github.io/cian-monitor/`.
Источник — список квартир агента 118101459 через неофициальный RealtyAPI (`/agent/offers`). Монитор проверяет агента, тип объявления, пагинацию и количество результатов; при неполном или ошибочном ответе не меняет статусы. Ключ хранится только в секрете репозитория `REALTYAPI_KEY` (Settings → Secrets and variables → Actions), не в коде и не на GitHub Pages.
На главной странице «Кладовой Алтая» ссылки на него нет. В HTML раздела указан `noindex`, но это **не защита доступа**: репозиторий и GitHub Pages публичны, поэтому любой обладатель прямой ссылки сможет открыть страницу и данные.

GitHub Actions запускает `.github/workflows/monitor.yml` ежедневно в 18:00 по Москве (15:00 UTC). Для ручного запуска: **Actions → Monitor Cian → Run workflow**. Новые объявления появляются на странице после ближайшей успешной проверки, а не сразу после размещения на Циан. Workflow должен иметь право `contents: write`, чтобы сохранять `data/state.json`, таблицу, статус и Excel-файл в ветку `main`. GitHub Pages продолжает публиковаться из `main / (root)`; переключать его на публикацию через Actions не нужно.

Первый снимок из пяти объявлений внесён 14 октября 2026 года. RealtyAPI отдаёт текущие цену, этаж, этажность, год постройки и материал дома. Газоснабжение и высота потолков в проверенном ответе API отсутствуют: ранее подтверждённые значения сохранены, остальные оставлены пустыми. Не следует выводить газ из упоминания плиты в описании. При ошибке API или исчерпании бесплатного лимита прежние данные сохраняются, но ежедневное обновление не гарантируется. «Нет в профиле» означает отсутствие объявления в последнем успешно прочитанном списке агента, а не подтверждение продажи. Срок считается с момента первого обнаружения монитором, не с даты публикации. «Первая цена» — первая записанная монитором цена, не обязательно первоначальная на площадке. История цен сохраняется в JSON, раскрывается на странице и выгружается на отдельный лист Excel. Снимок отражает цену на дату проверки, не точный момент изменения между проверками.
