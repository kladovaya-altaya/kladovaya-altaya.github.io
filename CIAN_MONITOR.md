# Монитор объявлений Циан

Отдельный раздел сайта: `https://kladovaya-altaya.github.io/cian-monitor/`.
Источник — список квартир агента 118101459 через неофициальный RealtyAPI (`/agent/offers`). Монитор проверяет агента, тип объявления, пагинацию и количество результатов; при неполном или ошибочном ответе не меняет статусы. Ключ хранится только в секрете репозитория `REALTYAPI_KEY` (Settings → Secrets and variables → Actions), не в коде и не на GitHub Pages.
На главной странице «Кладовой Алтая» ссылки на него нет. В HTML раздела указан `noindex`, но это **не защита доступа**: репозиторий и GitHub Pages публичны, поэтому любой обладатель прямой ссылки сможет открыть страницу и данные.

GitHub Actions запускает `.github/workflows/monitor.yml` ежедневно в 18:00 по Москве (15:00 UTC). Для ручного запуска: **Actions → Monitor Cian → Run workflow**. Новые объявления появляются на странице после ближайшей успешной проверки, а не сразу после размещения на Циан. Workflow должен иметь право `contents: write`, чтобы сохранять `data/state.json`, таблицу, статус и Excel-файл в ветку `main`. GitHub Pages продолжает публиковаться из `main / (root)`; переключать его на публикацию через Actions не нужно.

Первый снимок из пяти объявлений внесён 14 октября 2026 года. RealtyAPI отдаёт текущую цену, площадь кухни, этаж, этажность, год постройки, материал дома, дату `addedTimestamp` и способ добраться до метро (`walk` / `transport`). `addedTimestamp` может означать обновление/повторное размещение, поэтому **не используется как дата первой публикации**. Для пяти исходных объявлений первая дата сверена с `publicationDate`/`creationDate` в карточках Циана; новые объявления получают её из API, если поле присутствует, иначе монитор пытается прочитать карточку Циана. Если исходная дата недоступна, срок остаётся пустым, а не подменяется датой обновления. Дни считаются включительно с первой публикации. `transport` показывается как «на транспорте»: API не уточняет, автомобиль это или общественный транспорт. Газоснабжение, высота потолков и балкон/лоджия в проверенном ответе API отсутствуют. Подтверждённые по открытым карточкам Циана значения сохранены вручную; для остальных объявлений пустые поля означают «не проверено», а не отсутствие признака. Не следует выводить наличие газа в доме только из упоминания плиты в описании. При ошибке API или исчерпании бесплатного лимита прежние данные сохраняются, но ежедневное обновление не гарантируется. «Нет в профиле» означает отсутствие объявления в последнем успешно прочитанном списке агента, а не подтверждение продажи. «Первая цена» — первая записанная монитором цена, не обязательно первоначальная на площадке. RealtyAPI не отдаёт предыдущие цены. История цен сохраняется в JSON, раскрывается на странице и выгружается на отдельный лист Excel. Снимок отражает цену на дату проверки, не точный момент изменения между проверками.

Отдельный файл `cian-monitor/archive.json` содержит 18 старых записей за 2026 год, перенесённых из заметок пользователя. Они **старые, неточные и не сверены с Цианом**. Даже при совпадении адреса и площади их нельзя автоматически объединять с объявлением из RealtyAPI без подтверждённого ID Циана. Исчезновение или закрытие не равно доказанной продаже; формулировка «продано» приводится только как утверждение из заметок пользователя. Старые цены и события показываются в отдельном блоке страницы и на листах Excel «Старый архив» и «Цены старого архива». Покупка 5 950 000 ₽ и ремонт 2 100 000 ₽ для первой записи также относятся к заметкам пользователя. Ежедневный генератор читает этот JSON при каждой выгрузке, но не изменяет его.
